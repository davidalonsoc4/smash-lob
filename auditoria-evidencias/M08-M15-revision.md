## Cruces examinados

- Resultado → confirmaciones → ranking/estadísticas/MVP: BUG-023 y BUG-030/031; los gates generales no detectaban estos escenarios.
- Propuesta → coordinación → reserva fijada → calendario: BUG-027 distingue vista recortada y helper que consulta propuestas; reserva manual se renderiza desde datos del partido.
- Participantes → pagos → historial de amistoso: BUG-032; no basta compartir layout si se cambian identidades.
- Cuotas/gastos → inicio → transparencia: helper normaliza jugadores únicos, organizador saldado, importes monetarios; mutaciones JSON necesitan control concurrente, relacionado con BUG-028.
- Evento → destinatario → Push → cola/lectura: la cola puede fallar silenciosamente (033), historial tiene cursor incompleto (039). Un estado leído no prueba entrega Push.

## Complemento de M04/M05/M07

El riesgo de guard concurrente de calendario se conserva separado como BUG-024 probable.
