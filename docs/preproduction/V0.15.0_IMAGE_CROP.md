# v0.15.0 - Image crop and optimization

Date: 2026-07-24

## Scope

- Add a reusable client-side crop dialog for profile avatars and league logos.
- Allow drag positioning, zoom and 90-degree rotation before saving.
- Produce normalized square 512 × 512 images.
- Use a circular preview for avatars and a square preview for league logos.
- Preserve alpha through WebP output where supported.
- Reject non-image files and images larger than 12 MB.

## Data and infrastructure

- No database migration.
- No API contract or authorization change.
- Existing data-URL storage flow is retained.

## Required validation

- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Manual avatar and transparent-logo checks on mobile and desktop.
