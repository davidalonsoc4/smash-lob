# v0.16.3 - Theme and visual style combinations

## Scope

- Separates the base theme from the visual style.
- Adds a dedicated compact Themes and appearance screen.
- Supports Light, Dark and System combined with Plain or Colorful.
- Adds dark variants for all five prepared Colorful palettes.

## Local preference model

- `smash-lob-theme-mode`: `light`, `dark` or `system`.
- `smash-lob-visual-style`: `plain` or `colorful`.
- `smash-lob-colorful-palette`: `indigo`, `ocean`, `emerald`, `coral` or `sunset`.

Legacy `smash-lob-theme` values are migrated automatically. Existing Colorful users become Light + Colorful and keep their palette. Existing Light, Dark and System users keep the same base theme with Plain styling.

## Validation focus

- Test all six base combinations and the five palettes in Light and Dark.
- Confirm System reacts to operating-system theme changes while Colorful remains enabled.
- Confirm legacy preferences migrate without a flash or reset.
- Review cards, navigation, forms, ranking, modals, skeletons and semantic statuses.

No database migration, API contract, permission or remote persistence change is required.
