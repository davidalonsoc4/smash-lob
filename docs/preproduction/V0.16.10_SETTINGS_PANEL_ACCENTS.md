# v0.16.10 - Settings panel accent alignment

## Scope

- Replace the padding/background workaround used by row-based cards with an explicit internal accent strip.
- Apply the shared treatment to Settings, league administration and per-day availability panels.
- Keep Plain mode and regular Colorful cards unchanged.

## Implementation

- `AppCard` accepts an optional `accentStrip` prop.
- The strip is rendered as the first child of the card and clipped by the card's own `overflow-hidden` and border radius.
- Colorful row groups remove the layered background strip to prevent duplicate accents.
- The strip is hidden outside Colorful style, so no empty space is introduced in Plain mode.

## Validation

- Check all Settings groups with every Colorful palette in light and dark themes.
- Verify the strip starts and ends inside the rounded border without gaps or square protrusions.
- Verify league administration and custom day availability use the same geometry.
- Confirm Plain mode has no strip and no top gap.

No database migration, API contract or permission change is required.
