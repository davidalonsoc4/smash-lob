# v0.17.13 - Taller season summary image

## Scope

Refine the generated season-summary image used by both **Compartir** and **Guardar imagen** so it fits a taller, more Instagram-like format and improves information legibility.

## Changes

- Increased the generated image canvas to a taller vertical format.
- Kept a single generation flow so the shared and downloaded image remain identical.
- Reworked the hero section to give champion and MVP more space and stronger hierarchy.
- Rebuilt the podium rows with clearer position badges, player names and points pills.
- Enlarged the highlight cards and increased text capacity to make the summary easier to read.
- Preserved theme-aware styling for Classic and Colorful modes.

## Technical notes

- No migrations are required.
- No API routes or persistence contracts change.
- Only the client-side image renderer and version/changelog metadata are updated.
