# Smash & Lob v0.17.8 - Individual statistics refinement

Date: 2026-07-27

## Scope

This release refines the v0.17 statistics workspace around the application's individual-league model.

## Changes

- Shows a global floating success confirmation after creating or editing a match result.
- Adds `/statistics/evolution`, with all season players on one position/points chart.
- Allows hiding individual series, restoring all players and focusing the top four.
- Uses categorical colors, dash patterns and marker shapes so series do not depend on color alone.
- Keeps detailed player comparison limited to two players; the league evolution route covers broad multi-player comparison.
- Removes pair rankings, pair win counters, pair win-rate records and shared-match comparison blocks.
- Keeps only the individual `strongest teammate` insight, ranked by aggregate set differential and then game differential.
- Hides habitual-opponent frequency in balanced calendars and shows the toughest opponent instead.
- Removes season selectors from statistics detail routes. They consume the season selected on `/statistics` through the existing query-state navigation.
- Replaces generic statistics-navigation symbols with meaningful standings, comparison, player, evolution, records and season icons.
- Replaces pair-oriented season-summary highlights with the biggest comeback.

## Compatibility

- No Supabase migration.
- No API contract change.
- No permission change.
- No persisted sports result or ranking mutation.
- Existing URLs keep working; the new evolution route is additive.

## Validation gates

Run, in order:

1. `npm run lint`
2. `npx tsc --noEmit`
3. `npm run build`

Then validate result saving, statistics navigation, balanced/manual calendar behavior, all-player chart visibility controls and all visual themes.
