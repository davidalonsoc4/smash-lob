# v0.16.1 - Location display consistency

- Added one shared formatter for stored schedule-location strings and location objects.
- Notification cards rebuild scheduled-match and upcoming-match copy from structured metadata instead of rendering legacy descriptions that may contain JSON.
- Activity, match schedule summaries, Google Calendar links and CSV exports now use the same readable venue/court label.
- Added dedicated Colorful-mode accents for notification, activity and schedule cards.
- Existing stored schedule values remain unchanged and no database migration is required.

```powershell
npm run lint; npx tsc --noEmit; npm run build
```
