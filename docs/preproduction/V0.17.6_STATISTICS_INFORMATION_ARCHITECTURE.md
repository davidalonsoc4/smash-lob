# v0.17.6 - Statistics information architecture

Date: 2026-07-26

## Goal

Reduce the cognitive load of the Statistics area without removing any of the competitive information introduced in v0.17.

## Changes

- Replaced the long statistics landing page with a compact season overview.
- Added dedicated routes for standings, player comparison, individual analysis, records and season summary.
- Added a shared statistics workspace hook so every route uses the same counted matches, season and ranking calculations.
- Preserved the selected season in the URL while navigating between statistics routes.
- Kept charts, records, data-quality information and shareable summaries available in their appropriate detail pages.
- Added compact navigation rows and responsive separators for Classic and Colorful themes.

## Routes

- `/statistics`
- `/statistics/standings`
- `/statistics/compare`
- `/statistics/player`
- `/statistics/records`
- `/statistics/season`

## Data and compatibility

- No database migration.
- No API contract change.
- No permission change.
- No statistical formula or stored result change.
