# v0.16.2 - Colorful appearance palettes

## Scope

- Adds five prepared palettes to the Colorful appearance:
  - Indigo and violet
  - Blue and turquoise
  - Emerald green
  - Coral and pink
  - Orange and purple
- Stores the selected palette locally under `smash-lob-colorful-palette`.
- Applies the palette before React hydration to prevent a default-palette flash.
- Keeps light, dark and system appearances unchanged.

## Visual system

Each palette defines coordinated primary, secondary, accent, warm and cool colours plus tinted backgrounds, surfaces, borders, text hierarchy, shadows and loading skeletons. Shared Colorful-mode rules consume these variables across navigation, cards, forms, standings and floating controls.

Semantic match, payment, warning, success and error colours remain independent from the visual palette. League-level status-colour disabling continues to neutralize those labels.

## Validation checklist

1. Select Colorful mode and switch through all five palettes.
2. Confirm immediate updates without a page reload.
3. Reload and reopen the PWA with each palette selected.
4. Switch to Light, Dark and System and confirm no visual regression.
5. Review Home, Ranking, Matches, match details, Notifications, Activity, Statistics, Profile and Settings.
6. Verify forms, dialogs, skeletons, empty states and bottom navigation.
7. Verify semantic states and status-colour disabling remain readable.
8. Verify Spanish, English and Basque labels and Settings search keywords.

## Persistence and infrastructure

- Device-local preference only.
- No database migration.
- No API, permission or Supabase schema change.
