# v0.17.12 - League-wide statistics and player progress

Date: 2026-07-27
Branch: `feature/v0.17-advanced-statistics`

## Scope

- Make the fixed player selectors fully opaque and visually separated from the content below.
- Add a `Toda la liga` statistics scope when a league has more than one season.
- Aggregate all valid matches and player performance across every season without carrying win streaks across season boundaries.
- Keep the season selector hidden when the league contains only one season.
- Replace the individual round-by-round table with a metric-switchable line chart.
- Separate seasons in evolution charts and reset position, points and game differential for each competition.

## Functional behavior

### Floating selectors

- Head-to-head and Individual analysis keep the existing real fixed behavior.
- The floating card now uses an opaque theme surface, a defined border and a stronger exterior shadow.
- Colorful themes preserve their palette accent while removing transparency and backdrop blur.

### Whole-league statistics

- The statistics landing selector becomes an `Ámbito` selector when several seasons exist.
- Available values are `Toda la liga` and every individual season.
- The whole-league scope combines valid results for rankings, records, comparisons, player analysis, opponents and teammates.
- Best-win-streak calculations reset at every real season boundary.
- Shareable final summary images remain season-specific because champions, MVPs and podiums belong to a concrete competition.

### Evolution charts

- Individual analysis offers `Posición`, `Puntos` and `Dif. juegos`.
- Every point preserves the round, teammate, opponents, result and change from the previous round.
- Whole-league charts concatenate real seasons in chronological order, display `Tn · Jn` labels, draw a separator and do not connect one season to the next.
- Position, points and game differential restart from each season's own calculation rather than creating a fictitious continuous competition.

## Persistence and deployment

- No database migration is required.
- No API contract, authorization rule or stored data changes.
- All calculations remain client-side over the existing validated match data.

- Aggregation smoke test passed for accumulated ranking, season-boundary streak reset, round labels and match context.
