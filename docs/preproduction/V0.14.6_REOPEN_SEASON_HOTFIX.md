# Smash & Lob v0.14.6 — Reopen season hotfix

## Problem

Reopening a finished season reused the generic season-start flow. That flow can inspect roster setup and, for self-registration seasons, attempts calendar generation intended only for a first start. A finished season must instead retain the data with which it was originally played.

## Resolution

- Added a dedicated server mutation for reopening finished seasons.
- The mutation only reactivates the selected season, updates the league active-season pointer, and loads the existing matches.
- It does not modify `season_settings`, `season_players`, players, registration state, schedule mode, or match pairings.
- The existing start flow remains unchanged for upcoming seasons.

## Data impact

No database migration is required. Existing players, matches, results, settings, and historical data are preserved.

## Required validation

- Reopen a finished fixed-roster season and verify the same players and matches remain.
- Verify the season becomes active and the league points to it as the active season.
- Verify no new matches are created and no registration mode changes.
- Finish and reopen a test self-registration season to verify the same preservation behavior.
