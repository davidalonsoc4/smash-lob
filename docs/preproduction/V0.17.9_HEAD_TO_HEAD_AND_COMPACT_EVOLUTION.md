# Smash & Lob v0.17.9 - Head-to-head and compact league evolution

Date: 2026-07-27

## Scope

This release separates direct player comparison from the global season-evolution view and makes the all-player chart denser and easier to read.

## Changes

- Renames `/statistics/compare` from `Comparar jugadores` to `Cara a cara`.
- Keeps the comparison route limited to two players and removes its duplicated evolution chart.
- Preserves the player summary cards, recent form and direct-rivalry panel.
- Changes the league-evolution shortcut from the top four to the top three players.
- Places the Position/Points and All/Top 3 selectors on the same row.
- Removes the repeated chart heading and keeps only a compact interaction hint.
- Shows every integer position between the best and worst visible positions.
- Fits up to seven rounds without horizontal scrolling and uses proportional scrolling for longer seasons.

## Compatibility

- No Supabase migration.
- No API contract change.
- No permission change.
- No persisted sports result or ranking mutation.
- Existing `/statistics/compare` URLs remain valid.

## Validation gates

Run, in order:

1. `npm run lint`
2. `npx tsc --noEmit`
3. `npm run build`

Then validate the two-player selector, direct-rivalry panel, Top 3 shortcut, position ticks and chart width with seven and more than seven rounds.

The review archive does not include `node_modules`. Focused TypeScript syntax and chart-logic checks passed, but the three project gates must be run in the local staging worktree; dependency installation was unavailable in the review environment because its package registry returned HTTP 503.
