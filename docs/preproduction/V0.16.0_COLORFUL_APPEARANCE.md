# Smash & Lob v0.16.0 — Apariencia Colorida

## Objetivo

Añadir una cuarta apariencia visual, independiente de Claro, Oscuro y Sistema, que dé más personalidad a la aplicación sin modificar la lógica de negocio ni la lectura de los estados funcionales.

## Alcance

- Nueva preferencia `colorful`, guardada en `localStorage` para el dispositivo actual.
- Aplicación temprana desde `layout.tsx` para evitar destellos del modo claro durante la carga.
- Vista previa y selector 2 × 2 en Ajustes.
- Capa global centralizada en `globals.css` para fondos, superficies, bordes, sombras, textos y formularios.
- Adaptación específica de tarjetas, estadísticas, ranking, navegación inferior, controles flotantes, títulos y skeletons.
- Conservación del sistema de colores semánticos y de la opción de la liga para neutralizarlos.
- Búsqueda de Ajustes actualizada para localizar el modo Colorido.
- Traducciones en español, inglés y euskera.

## Decisiones visuales

- Base clara azul lavanda con degradados suaves.
- Acento principal índigo y violeta.
- Acentos secundarios rosa, ámbar y azul cielo.
- Superficies blancas translúcidas con bordes tintados y sombras suaves.
- Contraste de texto mantenido sobre fondos claros.
- Sin animaciones obligatorias cuando el dispositivo solicita reducir movimiento.

## Fuera de alcance

- No cambia el logotipo de la aplicación.
- No modifica colores guardados en la base de datos.
- No añade migraciones.
- No altera permisos, APIs, calendarios, resultados ni estadísticas.
- No convierte Colorido en una variante oscura; es una apariencia clara independiente.

## Validación requerida

```powershell
npm run lint; if ($LASTEXITCODE -eq 0) { npx tsc --noEmit }; if ($LASTEXITCODE -eq 0) { npm run build }
```

Pruebas manuales:

1. Cambiar entre Claro, Oscuro, Sistema y Colorido sin recargar.
2. Recargar con Colorido activo y comprobar que no aparece un destello claro.
3. Revisar Home, Ranking, Partidos, Perfil, Ajustes y Administración.
4. Comprobar estados de partido, pagos, MVP, avisos y errores.
5. Activar y desactivar los colores de estado de la liga.
6. Revisar móvil, PWA, modo horizontal y preferencia de movimiento reducido.
