# v0.15.2 - Actionable empty states

Date: 2026-07-24

## Scope

- Add a reusable empty-state component with optional primary and secondary actions.
- Replace isolated empty messages on the most-used personal and administrative screens.
- Tailor descriptions and next actions to the current context.
- Keep compact variants for dense admin screens.

## Covered screens

- Matches
- Notifications
- Activity
- Personal suggestions
- Application suggestion review
- Announcements
- Substitute pool and history
- Statistics and season history

## Data and infrastructure

- No database migration.
- No API, permission or persistence changes.

## Required validation

- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Manual checks for each empty screen in light and dark mode.
