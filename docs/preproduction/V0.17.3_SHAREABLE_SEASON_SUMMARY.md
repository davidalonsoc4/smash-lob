# v0.17.3 · Resumen final compartible

Fecha: 2026-07-26

## Incluido

- Tarjeta final para temporadas terminadas.
- Campeón, MVP, podio y cuatro hitos competitivos.
- Generación local de PNG a 1080 × 1350 píxeles.
- Compartir mediante Web Share API cuando el dispositivo lo permite.
- Descarga automática como alternativa.
- Colores adaptados al tema y paleta activos.

## Validación manual

1. Abrir una temporada terminada y revisar el resumen.
2. Verificar temporadas con MVP único, compartido y sin MVP.
3. Guardar la imagen desde escritorio.
4. Compartir desde un dispositivo móvil compatible.
5. Revisar la imagen con Clásico claro, Clásico oscuro y varias paletas Coloridas.
6. Confirmar que una temporada activa no muestra resumen final.

## Persistencia

La imagen se genera en el navegador. No requiere migraciones, API ni almacenamiento remoto.
