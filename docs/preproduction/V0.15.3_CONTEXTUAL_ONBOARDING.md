# v0.15.3 - Contextual onboarding

Date: 2026-07-24

## Scope

- Add dismissible contextual tips for settings search, per-day availability, match actions and season administration.
- Persist dismissed tips locally per device.
- Add a Help control to restore all contextual tips.
- Provide Spanish, English and Basque copy.

## UX rules

- Tips never block navigation or interaction.
- Tips only appear where the related function is available.
- Dismissal is reversible.
- No account or server data is used to track onboarding state.

## Data and infrastructure

- No database migration.
- No API, authorization or remote persistence change.
- State is stored only in browser `localStorage`.

## Required validation

- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- Manual dismiss/reset checks in all three languages.
