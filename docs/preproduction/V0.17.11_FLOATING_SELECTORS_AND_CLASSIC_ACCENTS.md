# v0.17.11 - Floating selectors and Classic accents

Date: 2026-07-27
Branch: `feature/v0.17-advanced-statistics`

## Scope

- Replace the ineffective CSS-only sticky player selectors with a shared selector that becomes a real fixed layer after its original position leaves the viewport.
- Keep the original layout height while the selector is floating so the page does not jump.
- Keep both Head-to-head player fields and the Individual analysis player field editable while floating.
- Return the selector to its normal document position when the user scrolls back up.
- Add restrained grayscale gradient accent strips to application cards in Classic light and Classic dark styles.

## Implementation notes

- `FloatingStatisticsSelector` uses an intersection sentinel to activate the fixed layer and a resize observer to preserve the selector's measured height.
- The fixed selector is centered inside the existing 448 px application shell, leaves room for the floating controls and stays below their z-index.
- Classic light uses a charcoal-to-silver gradient; Classic dark reverses the emphasis toward silver and graphite.
- Colorful palettes and their existing card gradients remain unchanged.
- Reduced-motion devices do not receive the selector entrance animation.

## Validation required in PRE

1. Open Head-to-head, scroll until the original selector reaches the upper controls and verify that it becomes fixed at the top.
2. Change both players from the fixed selector and verify that all statistics update.
3. Scroll back to the page header and verify that the selector returns to its normal position without a layout jump.
4. Repeat the same checks in Individual analysis.
5. Check Classic light and Classic dark on cards with ordinary content, row content and long pages.
6. Check that Colorful light and dark card accents remain unchanged.
7. Run `npm run lint`, `npx tsc --noEmit` and `npm run build`.

No migration, API, permission or persistent-data change is required.
