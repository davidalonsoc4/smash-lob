# v0.16.5 — Visual closure and Settings search

Date: 2026-07-25

## Scope

- Move the existing global Settings search launcher from the main Settings page into `AppShell`.
- Display it only on navigation hubs: Settings, League administration, My leagues and Application administration.
- Keep action/form screens free from an additional floating control.
- Contain the Colorful card accent strip inside the card border without forcing card content clipping.
- Improve recognition of muted buttons and links on dark Colorful palettes with a subtle inset outline and stronger active state.

## Compatibility

- Search results continue to respect spectator, league administrator, creator, superuser and QA capabilities.
- Plain Light, Dark and System themes are unaffected.
- No database migration, API contract, permission or remote persistence change is required.

## Manual validation

1. Confirm the search button appears on `/settings`, `/admin`, `/leagues` and `/application-admin`.
2. Confirm it does not appear on `/settings/profile`, `/settings/appearance`, `/settings/notifications`, `/admin/league`, `/admin/season` or other action screens.
3. Test search results as player, spectator, league administrator and superuser where available.
4. Review Home cards in every Colorful palette and verify the top accent remains inside rounded corners.
5. Review neutral secondary actions in every dark Colorful palette and confirm they read as interactive controls.
6. Run lint, TypeScript and production build before commit.
