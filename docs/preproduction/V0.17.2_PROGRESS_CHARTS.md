# v0.17.2 · Gráficos e historial competitivo

Fecha: 2026-07-26

## Incluido

- Gráfico comparado de posición por jornada.
- Gráfico comparado de puntos acumulados.
- Cambio de métrica sin abandonar la selección de jugadores.
- Colores coordinados con las paletas Coloridas.
- Etiquetas SVG y resumen alternativo para accesibilidad.

## Validación manual

1. Comparar dos jugadores con varias jornadas.
2. Cambiar entre Posición y Puntos.
3. Cambiar uno de los jugadores y verificar la actualización inmediata.
4. Revisar temporadas con una sola jornada y temporadas sin resultados.
5. Probar las seis paletas en claro y oscuro.
6. Comprobar el desplazamiento horizontal en pantallas estrechas.

## Persistencia

No requiere migraciones, API ni nuevas dependencias.
