# v0.17.17 - Taller season summary readability

## Scope

Refine the compact monochrome season-summary export so long highlight text stays readable, hero panels use the full width and the final image recovers some vertical breathing room.

## Changes

- Move the highlight section back to a single-column stack.
- Render champion and MVP hero panels as full-width stacked cards.
- Slightly increase the image height and internal spacing.
- Keep the monochrome palette and clear hierarchy introduced in v0.17.16.
- Keep points, victories and games-difference data in the hero panels and podium.

## Technical notes

- No migrations are required.
- No API routes or persistence contracts change.
- The work is limited to the client-side season-summary preview/export components and version metadata.
