# v0.16.4 - Visual consistency, action feedback and image viewer

Date: 2026-07-25

## Scope

- Consolidate transient success confirmations in the global action-feedback center.
- Improve text and control contrast across all Colorful palettes, with special attention to dark mode.
- Add an accessible expanded viewer for league logos and main player profile images.

## Action feedback

The following operations now use the floating feedback center instead of duplicating a success line inside the form:

- League identity, logo and habitual locations.
- Account name and profile image.
- Availability, notification preferences and suggestions.
- Activity settings, payment reminders and registration reminders.
- Season rule and administration saves.
- League-user administration and application-user actions.
- Match incident reporting/resolution and league announcements.

Contextual errors remain next to the affected field or form. Existing retry actions are preserved.

## Colorful contrast review

- Added a palette-specific foreground for primary buttons and active navigation.
- Improved low-priority text contrast in all five dark Colorful palettes.
- Added dark Colorful variants for semantic success, error, warning and information surfaces.
- Improved disabled form-field legibility without relying on reduced opacity.
- Preserved league status-colour behaviour and the option to neutralise status colours.

## Expanded image viewer

- Main league logos can be opened from Home, the league selector, League administration and spectator invitations.
- Player images can be opened from My profile, player profile and player MVP profile screens.
- The viewer preserves the image aspect ratio and closes from the close button, backdrop or Escape key.
- Background scrolling is locked while the viewer is open.
- Keyboard focus indication and accessible dialog labels are included.

## Persistence and backend impact

- No database migration.
- No API contract change.
- No permission change.
- No new remote persistence.
