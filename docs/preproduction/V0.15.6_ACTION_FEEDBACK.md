# v0.15.6 - Action feedback and connection recovery

## Scope

- Add a single global presentation layer for success, error, and informational action feedback.
- Keep page-level messages for context while making the result visible when the relevant form is outside the viewport.
- Detect browser offline/online events without changing server data or application permissions.
- Add direct retry actions to recoverable failures in availability, notification settings, and suggestions.

## User-visible behavior

- Feedback is displayed above the bottom navigation without shifting the page.
- Errors remain visible when they include a retry action; ordinary confirmations close automatically.
- Offline status remains visible until connectivity returns.
- Returning online triggers a short confirmation.
- Profile name and avatar changes, availability saves, notification changes, and suggestion submissions publish global feedback.

## Validation

Run locally before merging:

```powershell
npm run lint; if ($LASTEXITCODE -eq 0) { npx tsc --noEmit }; if ($LASTEXITCODE -eq 0) { npm run build }
```

Manual checks:

- Save profile name and avatar.
- Save availability and force a failed request before retrying.
- Toggle notification preferences and device subscription.
- Submit a suggestion and retry a failed submission.
- Toggle browser offline mode and confirm persistent/recovery feedback.
- Verify light/dark mode and mobile safe areas.

No migration, API contract, permission, or database change is required.
