# v0.16.9 - Transparent league logos

- Added automatic output selection to the shared image cropper.
- Cropped league logos with transparent pixels are encoded as PNG while they remain within the existing 512 KiB embedded-image limit.
- Transparent outputs that would exceed the limit fall back to WebP, which preserves the alpha channel while reducing size.
- Fully opaque league logos keep the previous 512 x 512 WebP output at quality 0.88, so their current visual result and storage behavior do not change.
- Audited `LeagueLogo`: it already renders through a transparent container with `object-contain`, covering Home, league selection, administration, spectator invitations and the image lightbox.
- The supplied 1254 x 1254 example PNG contains a real alpha channel and is compatible with this flow.
- No migration, API contract, permission or remote persistence change is required.
