# v0.17.15 - Season summary export polish

## Scope

Refine the season-summary page preview and exported image so the hero panels are more informative, the podium includes the games-difference tiebreaker and the exported asset stays readable under any active theme.

## Changes

- Merge champion and MVP into one panel when both roles match the same player set.
- Add points, victories and games difference to champion and MVP panels.
- Add games difference to podium rows in the page preview and exported image.
- Remove the extra intermediate counters for highlighted positions and highlighted moments.
- Increase the spacing between Podio final and Lo más destacado.
- Force a predominantly light exported canvas background independently from the current app theme.

## Technical notes

- No migrations are required.
- No API routes or persistence contracts change.
- The work is limited to the client-side season-summary data mapping and renderer plus version/changelog metadata.
