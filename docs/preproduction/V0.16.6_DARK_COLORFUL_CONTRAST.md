# v0.16.6 - Dark Colorful contrast closure

Date: 2026-07-26

## Scope

- Remove the palette-coloured glow around the fixed top action controls in dark Colorful themes.
- Preserve a clear primary hierarchy for the invite share action without a luminous halo.
- Restore readable muted labels and supporting copy rendered on palette-primary surfaces.
- Cover the shared pattern used by player statistics, MVP summaries, selected options and equivalent cards.

## Implementation

- `app-floating-control` now uses a compact neutral shadow and a slightly tinted dark surface.
- `app-floating-primary-control` provides a dedicated primary treatment for the invite share action.
- Muted neutral text utilities nested inside a `bg-neutral-950 text-white` surface inherit a mixed version of `--colorful-on-primary`.
- The fix is centralized in theme CSS; no page-specific data or behavior changes are introduced.

## Validation checklist

1. Open Home with Dark + Colorful + Indigo/Violet.
2. Confirm Share, spectator, notifications and settings controls do not show an outer coloured halo.
3. Confirm the Share action remains visually primary.
4. Open Profile and confirm Victory and Balance labels are readable.
5. Review MVP summary cards and selected option cards for the same muted-on-primary pattern.
6. Repeat with all five palettes in light and dark variants.
7. Confirm Light/Dark/System with Plain style are unchanged.

## Persistence and backend

No database migration, API contract, permission, notification payload or remote persistence change is required.
