# Avatar Worlds Roadmap

1. Validate Pixel Chibi proportions, readability and controls in PRE.
2. Freeze recipe v1 and manifest v1 after visual feedback.
3. Extend or replace typed primitives with production-authored modules while retaining IDs and anchors.
4. Add screenshot baselines for 320/360/390/430 px.
5. Design the Chibi Illustrated template and renderer against the same recipe.
6. Add account persistence for recipe and viewer preference through dedicated APIs.
7. Integrate the common renderer into profile, standings and matches behind a rollout flag.
8. Add export rendering and caching.
9. Expand identity/body options and accessibility.
10. Promote only after independent security, performance and visual acceptance gates.
