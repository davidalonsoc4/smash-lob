# Manifest Schema

`public/avatars/shared/manifest.json` declares manifest and recipe versions, worlds, the master template, semantic asset IDs, categories, colour support, renderer tokens and compatibility exclusions.

A world variant may be `null`. Every `chibi_illustrated` entry is deliberately null in DEMO 0.1 so the UI never substitutes Pixel Chibi as a fake second world.

Portable structural schema: `public/avatars/shared/schemas/avatar-manifest.schema.json`.
