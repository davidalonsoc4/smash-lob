Countdown samples: 3, 2, 1 in English and Spanish, synthesized locally using Windows SAPI (Zira/Helena), trimmed and peak-normalized to PCM16 mono WAV. Each file is shorter than 0.5 seconds. No runtime TTS service or dependency is needed for these numbers.

The selected device voices apply to full announcements. Bilingual countdown uses the English samples once; Spanish mode uses Spanish samples. If a sample cannot load, the app plays a short tone. Live announcements still require the screen to be visible.
